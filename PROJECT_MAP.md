# Project Map

## Product identity

Working name: Peptide Discovery Flywheel

Positioning:
An agentic research graph for manufacturability-aware peptide discovery.

Better framing than:
- AI peptide generator
- Fully autonomous peptide manufacturer
- General AI drug discovery platform

## Core loop

Target → Hypothesis → Candidate Design → In-silico Evaluation → Manufacturability Screen → Synthesis/Assay Planning → Experimental Result → Failure Classification → Next Design

## Main components

1. Research DAG Core
2. Target Dossier Agent
3. Peptide Design Orchestrator
4. Candidate Card System
5. Manufacturability Scoring Engine
6. Structure and Simulation Agent
7. Red-Team Agent
8. Assay Planning Agent
9. CRO/CDMO Pack Generator
10. Failure Ontology
11. Active-Learning Agent
12. Reporting and Decision Record System

## Near-term build principle

Build thin vertical slices. Each project should create structured data that compounds into the next one.
