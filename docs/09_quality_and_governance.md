# Quality and Governance

## Core governance principle

The system should preserve traceability. Every recommendation should be linked to inputs, models, assumptions, versions and human decisions.

## Records to maintain

- Dataset source
- Model/tool version
- Prompt/version
- Candidate generation settings
- Prediction outputs
- Human approval decisions
- Vendor communication
- Analytical results
- Assay outcomes
- Failure classification
- Next-round rationale

## Human review gates

Human review should be required for:

- Target selection
- Experimental spend
- CRO/CDMO submission
- Therapeutic claims
- Clinical claims
- Patent filing decisions
- External reporting
- Any regulated development decision

## Audit trail

Every automated action should log:

- Agent name
- Time
- Input objects
- Output objects
- Uncertainty
- Assumptions
- Human approval status
