# Portfolio Demo Specification

## Demo title

Manufacturability-Aware Peptide Discovery Flywheel

## Demo objective

Show that the system can take one target and produce a structured design-make-test-learn campaign.

## Minimum demo flow

1. Select a safe, well-characterised target.
2. Generate target dossier.
3. Define a binding hypothesis.
4. Generate 10 to 30 peptide candidates.
5. Create candidate cards.
6. Score manufacturability.
7. Red-team top candidates.
8. Produce CRO-ready synthesis/assay package.
9. Ingest simulated or real results.
10. Classify failures.
11. Recommend next design round.

## Public-facing outputs

- Technical README
- Architecture diagram
- Example candidate cards
- Failure ontology
- Simulated campaign report
- Roadmap for real validation

## What this demonstrates

- Agentic workflow design
- Scientific data structuring
- Biophysics-aware reasoning
- Manufacturability awareness
- Translational thinking
- Venture-relevant technical direction
