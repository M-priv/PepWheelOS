# Validation and Assay Strategy

This document is a planning framework, not a wet-lab protocol.

## Validation principles

Every experiment should be tied to a hypothesis and rejection criterion.

Example:
If the hypothesis is target binding, the validation plan must distinguish true target binding from non-specific binding, aggregation, assay interference or artefact.

## Common validation categories

- Binding kinetics
- Functional effect
- Selectivity
- Solubility
- Stability
- Serum or protease susceptibility
- Analytical identity and purity
- Cytotoxicity
- Aggregation behaviour

## Candidate advancement logic

A candidate should not advance just because one score is strong. It should pass a minimum evidence package:

- Plausible mechanism
- Acceptable manufacturability risk
- Clean analytical result
- Measurable binding or functional signal
- No obvious off-target or artefact flag
- Clear next experiment

## Output expected from assay planning agent

- Assay goal
- Readout
- Control logic
- Acceptance criteria
- Rejection criteria
- Required sample information
- Result interpretation plan
