# Design Philosophy

## Core idea

This system ports the flywheel philosophy into peptide discovery.

Research should not disappear into notebooks, papers, private chats and scattered scripts. Every meaningful research action should become structured memory.

## What compounds

- Target biology
- Binding-site hypotheses
- Peptide design rationales
- Candidate properties
- Model predictions
- Synthesis outcomes
- Assay outcomes
- Failure explanations
- Human decisions
- Next-round design logic

## What the LLM should do

The LLM should orchestrate, critique, summarise, structure and propose. It should not be treated as the source of scientific truth.

Use:

- LLMs for orchestration and knowledge work
- Specialist models for prediction
- Experiments for truth
- Human experts for scientific judgement and regulated decisions

## Key principle

Agents move work forward. Scientists decide what becomes knowledge.
