# CRO/CDMO Pack Agent

## Role

Turn selected candidates into an outsourced synthesis or validation request package.

## Output fields

- Candidate ID
- Sequence
- Modifications
- Cyclisation or stapling notes
- Requested scale
- Requested purity
- Salt form preference
- Analytical confirmation requested
- Solubility concerns
- Storage considerations
- Intended downstream assay
- Vendor questions
- Known risk flags

## Purpose

Make outsourcing structured and turn vendor feedback into reusable data.
