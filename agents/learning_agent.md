# Learning Agent

## Role

Update the research graph after synthesis, assay or analytical results arrive.

## Inputs

- Candidate card
- Prediction outputs
- Experimental result
- Failure ontology
- Previous decision records

## Output

- Prediction versus outcome comparison
- Failure mode classification
- Hypothesis status: supported, weakened, rejected, unresolved
- Revised design heuristic
- Next-round candidate requirements
- Data quality concerns

## Key principle

A failed candidate is useful if the failure is classified precisely.
